# Contribuciones

Este es un proyecto de investigación independiente. Cambios mediante Issue → rama → PR → revisión → checks → merge. No cargue datos sensibles ni credenciales. Respete diseño propio, pruebas de dominios y Firestore, documentación del cambio, accesibilidad y validación móvil/tableta.

Consulte [docs/GOBERNANZA.md](docs/GOBERNANZA.md) y [docs/LANZAMIENTO.md](docs/LANZAMIENTO.md).
