# Divulgación responsable

Evite publicar datos reales, correos, contraseñas, tokens y procedimientos de explotación en issues públicos. Antes de invitar usuarios el propietario debe activar **GitHub Private vulnerability reporting** o designar un canal seguro de contacto y publicar el procedimiento.

Consulte [docs/SEGURIDAD.md](docs/SEGURIDAD.md) para amenazas, controles actuales y brechas por cerrar.
